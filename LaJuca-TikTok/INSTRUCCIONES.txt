LA JUCA TIKTOK LIVE - FONDO Y PORTADAS V3

1. Reemplaza index.html y server.py en tu instalación actual. Conserva logo.png.
2. Para habilitar YouTube como fuente alternativa:
   py -m pip install yt-dlp
3. Reinicia el servidor:
   py server.py
4. Abre http://127.0.0.1:8765 y fuerza recarga Ctrl+F5.
5. Comprueba http://127.0.0.1:8765/graffiti-background.jpg
6. Comprueba http://127.0.0.1:8765/api/nowplaying

El fondo se aplica directamente al escenario principal.
Las carátulas se buscan en iTunes, Deezer y opcionalmente YouTube.
YouTube ofrece miniaturas de videos, no siempre carátulas oficiales.
El audio y el archivo C:\LaJuca\metadata.txt no se modifican.
